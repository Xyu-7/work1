# 本地数据表

一个零依赖的纯前端数据表应用，外观和交互参考腾讯文档在线表格，带文档标题栏、工具条、公式栏、列字母和行号。支持查找、动态新增/删除/重命名列，单元格直接编辑并自动保存，所有数据保存在浏览器自带的 IndexedDB 中。

## 功能

- 文档式界面：顶部文档栏、工具条、公式栏、列字母、行号和单元格选中框
- 表格展示：表头吸顶、行号、网格线，类似 ERP 系统的文档记录列表
- 查找内容：顶部查找框支持跨列搜索，匹配单元格会高亮显示，按 `Ctrl + F` 可直接聚焦查找框
- 编辑单元格：点击任意数据单元格即可输入文字，移开焦点后自动保存
- 新增行：表格底部点击“+ 新增行”，在末尾追加空白行
- 删除行：每行最右侧有删除按钮，确认后删除
- 新增列：表格右上角点击“+ 新增列”，自定义列名并追加到末尾
- 删除列：列标题右侧的小叉，确认后删除整列
- 重命名列：双击列标题，直接修改列名
- 本地存储：IndexedDB 持久化，刷新或关闭页面后重新打开数据仍然存在
- 导出 CSV：下载当前完整表格
- 导入 CSV：选择本地 CSV 文件，确认后覆盖当前表格数据

## 本地运行

浏览器对 `file://` 页面使用 IndexedDB 的限制不一致，建议通过本地 HTTP 服务打开。

在本目录执行：

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 使用说明

- 单击单元格后直接输入，点击其他位置会自动保存
- 按 `Enter` 结束当前单元格编辑
- 按 `Esc` 放弃当前单元格尚未保存的输入
- 双击列标题进入重命名状态，按 `Enter` 保存，按 `Esc` 取消
- 导入 CSV 时默认第一行是列名，后续行是数据
- 导入会覆盖当前表格，执行前会弹出确认

## 数据存储

- 数据库名称：`registration-table`
- 当前数据库版本：`2`
- 列数据仓库：`columns`
- 行数据仓库：`rows`
- 旧版固定字段数据会自动迁移到新结构
- 数据只存在当前浏览器、当前访问地址对应的本地存储中
- 清除浏览器站点数据会同时清除表格数据
- 不同浏览器、不同设备之间不会自动同步

## 发布到 GitHub Pages

仓库上传完成后，在 GitHub 仓库页面进入：

`Settings` → `Pages` → `Build and deployment`

选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

保存后，站点地址通常是：

`https://Xyu-7.github.io/work/`
